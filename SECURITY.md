# Security Policy

## Reporting a vulnerability

Do not open a public issue for credentials, exploitable vulnerabilities, or sensitive safety bypasses

Email the EvoLink security contact directly at [support@evolink.ai](mailto:support@evolink.ai)

Include the affected file or URL, reproduction steps, impact, and a safe proof of concept

This repository documents public use cases and does not accept operational jailbreak instructions, leaked credentials, or harmful exploit payloads
